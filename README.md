# QuickSplit 💸
**Effortlessly Split and Settle Group Expenses**

QuickSplit is a fintech web app designed to simplify group expense management by automating debt calculations, making financial settlements smooth and transparent for all users. From trips to shared living, QuickSplit makes it easy to track, split, and simplify group expenses.

---

## 📌 Features

- **Expense Splitting 🧾**  
  Automatically divides shared expenses among group members with customizable splits. Users can adjust share percentages, accommodating varying contributions.

- **Dynamic Debt Simplification 🤖**  
  Uses an optimized algorithm to consolidate debts, minimizing redundant payments and reducing the number of transactions.

- **Personalized User Profiles 👤**  
  Users can view joined groups, track balances, and review past transactions. Profiles update dynamically based on user activity.

- **Optimized Performance 🚀**  
  Backend APIs minimize system load, enhancing speed and efficiency even with multiple users.

## 🚀 Getting Started

### Prerequisites
- Java JDK 11+
- Maven
- SQL Database (MySQL or PostgreSQL recommended)
- Eclipse IDE or any compatible Java IDE

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Krushit-Babariya/Quick-Split.git
   ```

2. **Navigate to the Project Directory**
   ```bash
   cd Quick-Split
   ```

3. **Set Up the Database**
   - Create a database in your SQL environment.
   - Update `application.properties` in `src/main/resources` with your database credentials.

4. **Build and Run**
   ```bash
   mvn clean install
   mvn spring-boot:run
   ```

5. **Access the App**
   - Open a browser and navigate to `http://localhost:4040`.
